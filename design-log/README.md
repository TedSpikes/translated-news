# Design Log

This folder is a running history of design and engineering decisions made on
this project. Each file captures the context, options considered, and the
rationale behind a specific change or feature — not just what changed, but why.

Files are named `<ISO-date>-<sequence>.md`, e.g. `2026-07-26-01.md`,
`2026-07-26-02.md`. Multiple entries on the same day increment the sequence
number.

See `.claude/skills/design-log/SKILL.md` for how this folder is used and
maintained during development.
