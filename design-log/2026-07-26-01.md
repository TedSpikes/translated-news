# Project kickoff: Israeli news, auto-translated to English

## What

New project: a desktop + mobile website that pulls headlines and article
previews from Israeli news RSS feeds and auto-translates them to English.
Hebrew is the initial source language, with more languages planned later.
Single-user (just Ted) for now — no multi-tenant concerns.

Three main parts:
1. RSS fetching (headlines + article previews)
2. Translation
3. GUI

Auth and caching are deliberately deferred — out of scope for the initial
build.

## Stack decisions

- **Backend:** Python + FastAPI. Chosen for async support, lightweight
  JSON API surface, and being simple to extend with auth/caching later.
  Flask was considered (simpler, no async) and Django (too much built-in
  structure/overhead for a solo project) — both rejected in favor of
  FastAPI's balance of minimal-but-capable.
- **Frontend:** Plain JS, no framework. Deliberately minimal for a
  single-user reading UI; avoids build-tooling overhead. May revisit if
  state management gets unwieldy as features (auth, caching, more
  languages) are added.
- **Storage:** SQLite. Zero-config, file-based, plenty for single-user
  scale. Easy to swap to Postgres later if the project ever grows beyond
  personal use.
- **Translation provider:** Google Cloud Translate. Chosen over the Claude
  API for cost/speed at this stage; tradeoff is less idiomatic/nuanced
  output than an LLM would give for headline translation. Revisit if
  translation quality on Hebrew headlines proves unsatisfactory.

## Initial RSS sources

Starting with two feeds, both Hebrew-language:

- Ynet: `https://www.ynet.co.il/Integration/StoryRss2.xml`
- Globes: `https://www.globes.co.il/webservice/rss/rssfeeder.asmx/FeederNode?iID=2`

Kept intentionally small to start — pipeline should be proven with two
sources before expanding to more outlets or languages.
